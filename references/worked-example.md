# 已完成的案例：park-cleanup（可作为对标基线）

一段读后续写范文（约 480 词）→ 3 分 59 秒、8 幕、57 条字幕的铅笔素描绘本动画。
所有数字都是实测，用来校准下一个项目的预期。

## 原始文本 → 字幕的量化校准

| 指标 | 值 |
|---|---|
| 词数 / 条 | 4–14，均值 8.4 |
| 时长 / 条（暂定） | 3.0–5.2s，均值 3.8s |
| 暂定语速 | 2.22 词/秒（133 词/分） |
| **TTS 净语速** | **2.2 词/秒**（条间另加 0.3s） |
| **等效语速（含间隔）** | **2.0 词/秒（120 词/分）** |
| 总长变化 | 216.4s → 239.6s（×1.107） |

两个语速口径别混用：`srt_from_text.py` 里 `--wps 2.2` 只管朗读本身，0.3s 间隔单独加；
480 词 / 239.6s 算出来的 2.0 是**含间隔**的等效值。拿 2.0 去当朗读速率会集体偏长。

## 两个真问题

**一、时间轴必须由配音反推。**
第一版按文本排 216.4s，配音后发现 `aria` 念得比窗口慢（4.6s 窗口念 5.6s），两句会叠。
改顺序后：逐条配音 → 按真实音长重排 SRT（239.6s）→ 元素起点锚到 `anchorCue`。
中间试过"按幕长等比缩放"，抽帧发现"捡罐"那句字幕出来时人还没画（晚 4.2 秒），
退回重写成锚点映射。**等比缩放一定偏，因为句内语速不是均匀的。**

**二、字幕得自己合成。**
本机 ffmpeg 8.1.1 编译时没带 libass 也没带 freetype，`subtitles`/`drawtext` 滤镜不存在。
改成 PIL 预渲染 57 张字幕贴图、逐帧 alpha 合成、numpy 铺音轨、一次编码出片。

## QA 里抓到的三处问题（都改掉了）

1. **S2 悬空前臂**：Ava 的手臂单独成区域，锚在第 13 条，身体锚在第 14 条，
   手臂画完后 1.8 秒身体才出现，中间一只前臂悬着。改成两段同锚第 13 条。
2. **S6 字幕赶在画面之前**：等比缩放导致 `and carefully picking up cans` 出现时
   拾罐的孩子还没画。改锚点映射后消失。
3. **S4 区域下部大片空白**：纸面噪点把 bbox 撑大。加连通域过滤（面积 <14 丢弃）后收边正常。

## 可复用的判断

- 一句话配一个元素，元素多到 4 个就该考虑拆幕，不要在一幕里塞。
- 元素时长低于 2.5 秒基本看不清笔迹，宁可在该幕结尾留白等下一句。
- 人物的手、脸这类细节区域，宁可显式写坐标，也别指望自动收边。
- 同一人物跨幕用固定外形标签描述，否则第 5 幕的孩子会变成另一个人。
